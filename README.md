# Tapeline

An ad-free measuring web app. Open it in Chrome on an Android phone.

**Camera (needs an ARCore phone + Google Play Services for AR):** tape measure, height, area & perimeter, angle, distance from phone, box volume, path length, level/plumb snapping, labelled photos, top-down room sketch PNG.

**Phone tools (any phone):** spirit level, tilt protractor, bank-card calibrated screen ruler, unit converter (incl. gaj, guntha, cent).

**Home estimates (sq ft, ₹):** paint, tiles & flooring, curtains, carpet vs built-up loading.

History stays in the browser on the phone. No accounts, no tracking, no ads.

Install: open the site in Chrome, menu → Add to Home screen.

Plain HTML, CSS and JavaScript modules. No build step. Served by GitHub Pages.
